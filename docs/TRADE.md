# Обмен 2.0 (Trade System 2.0)

Новый обмен между игроками: понятное окно «Ты отдаёшь / Ты получаешь», поиск и фильтры,
количество для одинаковых находок, проверка ценности, двойное подтверждение с удержанием и живые
обновления. Приглашение больше никого не блокирует.

## 1. Что изменилось для игрока

| Было | Стало |
|---|---|
| Приглашение сразу «запирало» цель в обмене на 240 с: она не могла продавать, пользоваться лабораторией и приютом, даже если не хотела меняться. | Приглашение — это просто запрос. Цель получает всплывающую карточку «Игрок предлагает обмен» с кнопками **ПРИНЯТЬ / ОТКЛОНИТЬ**. Пока она не приняла, её ничто не блокирует. |
| Приглашать можно было без ограничений (спам, гриферство). | Приглашение живёт 45 с. После отказа, истечения или отзыва тот же игрок может пригласить того же игрока снова только через 20 с. У одного игрока не больше 3 ожидающих приглашений. Если тебя уже пригласили, а ты приглашаешь в ответ — обмен просто начинается. |
| Окно перерисовывалось целиком, длинный список кнопок, без поиска. | Новое окно на UI-ките: две колонки карточек «ТЫ ОТДАЁШЬ» (синяя) и «ИГРОК ОТДАЁТ» (оранжевая), в центре — проверка ценности, статусы и одна большая кнопка. Под своей колонкой — выбор из инвентаря: вкладки **СОБАКИ / НАХОДКИ**, поиск, фильтр редкости, сортировка (редкость, ценность, новые). |
| 6 собак + 6 находок. | До **9 собак + 9 находок** + монеты. Одинаковые находки (тот же предмет и мутация) собраны в одну карточку с кнопками **− n/N +**; в колонках одинаковые записи показаны одной карточкой «×N». |
| Защиты почти не было, «LOCK» и «FINAL CONFIRM» путали. | Шаги: **1 ДОБАВЬ → 2 ГОТОВ → 3 защитный отсчёт 5 с → 4 УДЕРЖИВАЙ «ПОДТВЕРДИТЬ» (1 с)**. Любое изменение предложения снимает «ГОТОВ» у обоих. Обмен проходит, только когда подтвердили оба. |
| Оценка стоимости — просто число. | Полоса «ПРОВЕРКА ЦЕННОСТИ»: сколько ты отдаёшь и получаешь, вердикт «ЧЕСТНЫЙ ОБМЕН / ТЫ ОТДАЁШЬ НАМНОГО БОЛЬШЕ / ТЫ ПОЛУЧАЕШЬ НАМНОГО БОЛЬШЕ». Если ты отдаёшь в 3+ раза больше, чем получаешь, или отдаёшь легендарную (или более редкую) собаку/находку, перед подтверждением появляется сводка всех карточек с отдельным удержанием. Обмен при этом **никогда не запрещается** — это подсказка. |
| Защищённых вещей не было видно. | Заблокированные собаки, собаки в будках и на витрине, собаки в пути, находки в избранном (★), нетрансферные находки показаны неактивными; при нажатии — понятная причина. Сервер проверяет то же самое ещё раз. |
| Обновления — опросом. | Каждое изменение сразу приходит обоим игрокам (push). Партнёр изменил предложение — тост и подсветка его колонки. |
| — | Успешный обмен — короткий салют конфетти и «ОБМЕН ЗАВЕРШЁН!» (без эффекта при Reduced Motion / LowFX). |

Телефон: вместо колонок — вкладки **ОТДАЮ / ПОЛУЧАЮ / ДОБАВИТЬ**, центр превращается в нижнюю
панель с вердиктом, статусами, отсчётом и главной кнопкой.

## 2. Как попробовать в Studio

1. **Test → Clients and Servers → 2 Players** (или 3 — чтобы проверить приглашения от нескольких).
2. Обмен открывается с 5-го уровня. В командной строке **сервера**:
   ```lua
   local R=require(game.ServerScriptService.Economy.Runtime);local C=require(game.ReplicatedStorage.DogEconomy.Config)
   for _,pl in game.Players:GetPlayers() do R.Tx:Run({'p:'..pl.UserId},function(v)local p=v['p:'..pl.UserId];p.XP=C.XPForLevel(10);p.Cash=1e6;return true end);R.Refresh(pl) end
   ```
3. У игрока 1: кнопка **TRADE** в боковом меню → список игроков → **ОБМЕН** у игрока 2.
4. У игрока 2 появляется карточка приглашения (окно не открывается само). Проверь, что игрок 2
   может продавать находки, пока не принял. **ПРИНЯТЬ** → у обоих открывается окно обмена.
5. Добавь собак/находки/монеты, нажми **ГОТОВ** у обоих, дождись отсчёта, удерживай
   **ПОДТВЕРДИТЬ** у обоих. Проверь: изменение предложения снимает «ГОТОВ»; отдав много за мало,
   получаешь сводку; заблокированную собаку добавить нельзя.
6. **ОТКЛОНИТЬ** → у приглашавшего тост, повторное приглашение — через 20 с.
7. Выход игрока из игры во время обмена отменяет обмен у второго (тост).

## 3. Что настраивать и где

Все числа — в `src/ReplicatedStorage/DogEconomy/TradeRules.luau` (общий модуль сервера и окна):

| Параметр | Значение | Смысл |
|---|---|---|
| `MaxDogs`, `MaxItems` | 9, 9 | размер предложения (не больше 30 — лимит аргументов запроса) |
| `InviteSeconds` | 45 | сколько живёт приглашение |
| `InviteCooldown` | 20 | пауза «тот же → тому же» после отказа / истечения / отзыва |
| `MaxInvites` | 3 | ожидающих приглашений у одного отправителя |
| `SessionIdle` | 300 | обмен без действий дольше — отменяется |
| `ReviewSeconds` | 2 | после изменения «ГОТОВ» доступен через столько секунд |
| `ConfirmDelay` | 5 | защитный отсчёт после «ГОТОВ» обоих |
| `WarnRatio` | 3 | «отдаёшь в N раз больше» → предупреждение и сводка |
| `BigRank` | 5 | редкость (Legendary и выше) → сводка при отдаче |
| `VariantValue` | Normal 1 … Void 12 | множители ценности вариантов собак |

Ценность: собака = цена из каталога (для «секретов» с ленты — цена ленты) × вариант × мастерство /
возвышение / первое издание; находка = её цена продажи (`ItemValuation`, фиксируется при находке).
Уровень доступа к обмену — `Config.TradeLevel` (5). Тексты — `src/ReplicatedStorage/Localization/Trade.luau`.

## 4. Производительность

- Окно строится один раз и обновляется на месте; все списки — `Kit.VirtualGrid` (карточки только
  в видимой области, 3D-превью из общего кэша).
- Изменения приходят push-ом (`DogEconomyPush`, вид `Trade`), опроса нет; пока окно открыто,
  раз в 10 с — лёгкая страховочная проверка через общий кэш `Modules.Net`.
- Правки предложения копятся 0,45 с и уходят одним запросом (лимит сервера ≈ 1,5 запроса/с).
- Покадровых циклов нет. Таймер 1 Гц работает только пока открыт список игроков и в нём есть
  таймеры (приглашения/паузы). Конфетти — пул из 26 рамок, создаётся один раз.
- Сервер: всё в RAM, приглашения/паузы/зависшие обмены чистятся при каждом запросе обмена и
  каждом снимке состояния (`Engine:PruneTrades`), так что ничего не копится.

## 5. Для разработчика

**Файлы.** Сервер: `Economy/Engine.luau` (раздел «TRADES 2.0»), маршрутизация и push —
`Economy/Runtime.luau` (`TradePlayers`, `PushTrade`, ветки `TradeRequest/TradeCancel/Trade`).
Общие правила: `ReplicatedStorage/DogEconomy/TradeRules.luau`. Клиент: `Modules/TradeScreen.luau`
(Kit-окно `Key='Trade'`, маршрут `GUIIntegration.kitScreens`), `ScreenGui/TradeClient.client.luau`
(загружает модуль при старте, чтобы всплывающее приглашение работало при закрытом окне).
Старое окно (`EconomyScreens` Menus, статическая `TradePage`) больше не открывается:
`PawpadController.renderTrade` открывает только новое окно. Тесты: `tests/trade.luau`.

**Запросы** (`DogEconomyRequest`):

| Действие | Аргументы | Что делает |
|---|---|---|
| `TradeRequest` | `{Target}` | приглашение (или принятие встречного) |
| `Trade` | `{Action='Accept', Invite?/From?}` | принять (по умолчанию — самое новое) |
| `Trade` | `{Action='Decline', Invite?/From?}` | отклонить, запускает паузу |
| `Trade` | `{Action='Offer', Dogs, Items, Cash}` | заменить своё предложение целиком; сбрасывает «ГОТОВ» обоих |
| `Trade` | `{Action='Ready', Version}` / `{Action='Unready'}` | готовность |
| `Trade` | `{Action='Confirm', Version}` | подтверждение; второе подтверждение проводит обмен |
| `TradeCancel` | `{Target?}` | отменить обмен или отозвать свои приглашения |

**Push** (`DogEconomyPush`): `Trade` = `{Event, Trade, Players, Now}` на каждое изменение;
`Event.Kind`: `Invite`, `InviteGone` (`Reason`: Declined / Expired / Withdrawn / Busy / Left),
`Started`, `Changed` (`Action`), `Failed` (`Message`), `Cancelled`, `Left`, `Expired`, `Completed`
(`Offers`). `TradeInvite` — входящее приглашение (только цели). `Event.Names` — имена.

**Снимок** (`Snapshot`): `Trade` — вид обмена (`Engine:TradeView`: все старые поля `Id, Users,
Version, Offers{Dogs, Items, Cash, Prints, ItemPrints, Details, Estimated}, Ready, Confirmed, Expires,
Inviter, Accepted, UpdatedAt, ConfirmDelay, Details` + новые `Seq, Me, Partner, ConfirmIn, ReviewIn,
ExpiresIn, Limits, Fairness, Committing`); `Players` — игроки онлайн (старые поля + `InviteIn`,
`InviteOut`, `Cooldown`, `CanInvite`, `Block`).

**Тесты** (`lune run tests/trade.luau`, входят в `tools/check.sh`): настоящий `Engine` над
RAM-хранилищем — приглашение не блокирует цель, принятие, лимиты 9+9 и отказы (заблокированная,
работающая, на витрине, в пути, платная собака; находка в избранном, нетрансферная, с проверкой
рекорда), сброс «ГОТОВ» при любом изменении, отказ подтверждения до отсчёта, атомарный обмен собак,
находок и монет (+1 к `CompletedTrades`), переполнение склада без изменений в профилях, отказ и
пауза, истечение и очистка RAM, выход игрока, ценность, старые поля снимка, старый профиль без
счётчика, русский для всех строк окна и сервера. Плюс два сквозных теста окна: два экземпляра
`TradeScreen` (игроки 1 и 2) на макете UI-кита и `Net`, подключённом к настоящему `Engine`
(приглашение → карточка → принять → выбор собаки и двух одинаковых находок шагом «+» → монеты
«1.5k» → вердикт → ГОТОВ → отсчёт → удержание → сводка → обмен; отказ и пауза на кнопке; макеты
телефона; русский язык; выход партнёра).

**Безопасность.** Транзакция одна на оба профиля (`trade-<id>`, идемпотентна), перед ней заново
проверяются: вместимость (собаки и находки, с понятным сообщением для каждой стороны), отпечатки
собак и находок, блокировка/будка/витрина/избранное, политика платных предметов (PaidRandom).
Ошибка ничего не меняет в профилях; обмен остаётся открытым, «ГОТОВ» сбрасывается. Пока идёт
обмен (принятая сессия), продажа, лаборатория и приют недоступны — как раньше (`TradeByUser`).
Перезапуск сервера просто отменяет незавершённые обмены (в сохранениях ничего нет).
