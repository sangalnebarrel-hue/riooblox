# Модели находок: Глубина 3 и Глубина 4

42 находки Древних руин (Глубина 3) и Проклятых глубин (Глубина 4) теперь строятся кодом из
`ReplicatedStorage.Forge`: каждая — отдельный объект из шаров, эллипсоидов, цилиндров, клиньев и
повёрнутых деталей, с материалами (металл, фольга, стекло, мрамор, песчаник, ткань, неон) и
2–4 цветами. Старые кубические модели `DiscoveryModels` для этих id больше не нужны (они остаются
запасным вариантом, пока `DiscoveryVisuals` не переключён на `ItemModels.Get`).

- Рецепты: `src/ReplicatedStorage/DogEconomy/ItemModels/Depth3.luau` и `Depth4.luau`.
- Стиль глубин: Глубина 3 — песчаник, золото, лазурит, бирюза, Египет и рыцари; Глубина 4 —
  чернёное железо, кость, кровь, болезненно-зелёное и фиолетовое свечение.
- Акценты (`ItemAccent`): самоцветы, светящиеся сердцевины, золотые детали — мутации перекрашивают
  только их. Мелочи (иероглифы, заклёпки, стежки, трещины) — в `b:Detail`, на LOD 1 их нет.
- Бюджет: LOD 0 — 8…37 деталей, в среднем 24 (обычные проще, эпические/легендарные/секретные богаче), LOD 1 —
  не больше 13. Размер — как у старой модели (самая длинная сторона ±35 %), модель стоит на Y = 0,
  лицом к −Z.
- Проверка: `lune run tests/item_models_d34.luau` (рецепт для каждого id, сборка на LOD 0/1,
  бюджеты, размеры, акценты, нет света/звука/скриптов, нет двух одинаковых геометрий).
  Превью без Studio: сцена со `ItemModels.Build(id, lod)` → `tools/qa/scene.luau` → `tools/qa/render.py`.
