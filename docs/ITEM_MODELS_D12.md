# Модели находок: Глубина 1 (Задний двор) и Глубина 2 (Пещеры)

41 находка нарисована заново — у каждой своя трёхмерная модель из настоящих форм (шары,
эллипсоиды, цилиндры, клинья, повороты), материалов (металл, стекло, мрамор, дерево, ткань,
камень, неон) и 3–6 цветов. Старые воксельные модели из одинаковых кубиков больше не нужны.

- Код: `src/ReplicatedStorage/DogEconomy/ItemModels/Depth1.luau` и `Depth2.luau` — по одному
  рецепту на предмет (Forge). Загружает их `ItemModels.luau`: `ItemModels.Get(id, lod)` отдаёт
  копию готового шаблона.
- Размер и положение: как у старой модели (самая длинная сторона ±35 %), модель стоит на Y = 0,
  лицом к −Z.
- Детализация: LOD 0 — 12–33 детали (обычные проще, эпические/легендарные богаче), LOD 1 —
  не больше 14 деталей: только силуэт (мелочи в `b:Detail`).
- Акценты (`b:Accent`): 1–6 «главных» деталей (камни, светящиеся ядра, металлические детали) —
  мутации перекрашивают только их.
- Внутри моделей нет света, звуков, скриптов и частиц — эффекты добавляет тот, кто показывает
  модель.
- Посмотреть без Studio: `tools/qa/scene.luau` + `tools/qa/render.py`
  (сцена: `ItemModels.Build(id, 0)`). Проверка: `lune run tests/item_models_d12.luau`.

## Для разработчика

Рецепт: `R[id] = function(b, lod) ... end`, `b` — строитель Forge. Основной силуэт строится
всегда, мелочи — в `b:Detail(function() ... end)`. Общие приёмы в `Depth2.luau`: `crystal()` —
шестигранный кристалл (3 бруска + куб на вершине), `point()` — остриё друзы, `settle()` —
опускает неровный камень ровно на землю. Тест `tests/item_models_d12.luau` проверяет: рецепт
есть у всех 41 предмета, сборку на LOD 0/1, бюджеты (≤ 40 / ≤ 14 деталей, считая Root), размер
относительно старой модели, опору на землю, акценты, разнообразие форм и цветов, отсутствие
света/звуков/скриптов и уникальность геометрии.
