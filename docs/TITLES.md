# Титулы над персонажем

Раньше титулы были ключами в `p.Cosmetics` и показывались только табличкой над собаками в будках.
Теперь это отдельная система: титул висит **над головой игрока**, его видят все, у каждого
титула есть редкость, цвет (или переливающийся градиент), иконка-эмодзи и условие получения.
Все заработанные раньше титулы сохранились.

## Что видит игрок

* **Над головой** — плашка «иконка + название» в стиле редкости:
  * Common — простой текст на мягкой тёмной подложке;
  * Uncommon — плюс цветная рамка;
  * Rare — светящийся контур букв;
  * Epic — градиент;
  * Legendary — градиент с бегущим бликом;
  * Mythic / Secret — блик и мерцающие искорки ✦ (Secret — на тёмной «пустотной» подложке).
  Плашка не рисуется сквозь стены, пропадает дальше 90 стадов и немного уменьшается с расстоянием.
  Свой титул скрывается в режиме от первого лица.
* **Окно «ТИТУЛЫ»** (ключ `Titles`, кнопку в HUD добавляет другой блок; открыть можно
  `N.OpenPage("Titles")`): живой предпросмотр — твой аватар и титул ровно так, как его видят
  другие, кнопка «СНЯТЬ», счётчик «открыто N / M»; чипы категорий (ВСЕ, ОТКРЫТЫЕ, раскопки,
  глубины, собаки, шахта, лаборатория, общение, богатство, прогресс, события, коллекция);
  сортировка по редкости / прогрессу / названию; карточки: открытые — цветные с кнопкой
  «НАДЕТЬ», закрытые — приглушённые, с замком, полосой прогресса и подсказкой «как получить».
  Секретные титулы показываются как «???» до получения.
* **Тост «НОВЫЙ ТИТУЛ: 🏆 ЛЕГЕНДАРНЫЙ КОПАТЕЛЬ»** появляется, когда открылся новый титул
  (до трёх за раз, остальное — «+N ещё»).

**Старые титулы.** Каждый ключ `p.Cosmetics`, который у игрока уже есть, — тоже титул с id
`legacy:<ключ>` (категория «КОЛЛЕКЦИЯ»): титулы Догдекса (`Dex10`… — имя через
`DexRewards.TitleName`, например «КОЛЛЕКЦИОНЕР СОБАК»), наборов собак (`SetFood` → «НАБОР:
ВКУСНЯШКИ»), коллекций находок (`Discovery:<набор>:Normal|Heavy`), находок (`Finds100`),
престижа (`Prestige2`), глобальных раскопок (`Event3`), платные (`GoldenKennel`, `CyberKennel`,
`VoidAura`, `FounderPlaque`, `SupporterTitle`, `EventSupporter`). Надетый раньше титул
(`p.EquippedCosmetic`) один раз переносится над голову. Старый список COSMETICS тоже работает:
если там надеть титул коллекции, он появится над головой.

## Как проверить в Studio

1. Play. Над своей головой титула нет (новый игрок) — откройте окно: в командной строке клиента
   `require(game.Players.LocalPlayer.PlayerGui.ScreenGui.Modules.TitlesScreen).Open()`
   (или кнопкой, когда её добавит HUD-блок).
2. Найдите первое сокровище или купите собаку — в течение 15 секунд появится тост
   «НОВЫЙ ТИТУЛ», карточка станет цветной; «НАДЕТЬ» — титул появится над головой.
3. Быстрая проверка редкостей: в командной строке сервера взять профиль из памяти
   `local p=require(game.ServerScriptService.Economy.Runtime).Tx.Cache['p:'..<UserId>]` и
   выставить, например, `p.Prestige=3`, `p.Lifetime.TotalCoinsEarned=2e9` — через ≤ 15 с (профиль
   нормализуется на ближайшем тике работающей собаки или любом действии игрока) откроются
   ПРЕСТИЖ, ВОЗНЕСЁННЫЙ, МИЛЛИОНЕР, МИЛЛИАРДЕР (анимированные блики видны в окне и над головой).
4. Второй игрок (Test → Players: 2) видит титул первого; при отдалении > 90 стадов титул пропадает.
5. Камера от первого лица — свой титул скрывается.
6. Старый игрок: в том же профиле задать `p.Cosmetics.Dex30=true; p.EquippedCosmetic='Dex30';
   p.Titles=nil` — после следующей нормализации над головой «КОЛЛЕКЦИОНЕР СОБАК».

## Что настраивать и где

* `src/ReplicatedStorage/DogEconomy/TitleDefinitions.luau` — список `Titles.List`: название
  (`Text`/`RU`), иконка, редкость, цвет `Color` (до Rare) или `Gradient` (от Epic), категория,
  условие `Stat` + `Target`, подсказка `How`/`HowRU`, `Hidden` для секретных. **Id не
  переименовывать** (он сохранён у игроков). Новую статистику добавлять в `Titles.Stats`.
* Стили редкостей — `Titles.Styles` (подложка, рамка, свечение, градиент, анимация, искры).
* Расстояния и бюджеты отрисовки — начало `PlayerTitles.client.luau`
  (`MAX_DISTANCE` 90, `ANIMATE_DISTANCE` 50, `MAX_ANIMATED` 12, высота плашки, смещение).
* Частота проверки условий — `Features/Titles.luau`, `F.EvalSeconds = 15`.
* Тексты окна — `src/ReplicatedStorage/Localization/Titles.luau` (`Exact` — уникальные строки,
  `Window` — общие слова только для окна, чтобы не менять переводы других экранов).

## Производительность

* Сервер: проверка условий — не чаще раза в 15 с на игрока (метка времени в памяти сервера,
  в сохранение ничего не пишется); каждая статистика считается один раз за проход. Тест:
  200 «богатых» профилей — ~45 мс первый проход, ~9 мс повторный, ~8 мс на `Normalize` всех 200
  в Lune (`tests/titles.luau`).
* Клиент: одна BillboardGui на игрока (≈15 объектов), анимация только у Legendary+ в 50 стадах
  от камеры, не больше 12 одновременно, через **один** общий Heartbeat (30 Гц), который
  отключается, когда анимировать нечего. Набор анимируемых пересчитывается дважды в секунду.
  Low FX / Reduced Motion — всё статично.

## Для разработчика

* Данные: `p.Titles = {Version=1, Unlocked={[id]=unixTime}, Equipped="", Counters={Stone,
  StoneSeen, LegendaryFinds, FeedAt}, LegacySeen=""}`. Разблокировки вечные.
  * `Counters.Stone` — камень за всё время: `p.Resources.Stone` хранит только баланс, поэтому
    складывается каждое его увеличение (у старого игрока текущий баланс засчитывается один раз).
  * `Counters.LegendaryFinds` — при первом проходе = число разных Legendary/Secret предметов в
    коллекции, дальше +1 за каждую новую такую запись `p.DiscoveryFeed` (метка `FeedAt`).
  * `LegacySeen` — последний виденный `p.EquippedCosmetic` (само поле не меняется: его читает
    миграция скинов участка в `PlotRules`).
* Действие `TitleEquip {Id}`: `""` снимает; только открытые (перед проверкой — внеочередная
  оценка, чтобы только что заработанный титул надевался сразу).
* Снимок: `snapshot.Features.Titles = {Version, Equipped, Unlocked, Progress={[id]={Value,Target}}}`.
* `Runtime.Project` (одна строка) вызывает `Features.Titles.Project`: атрибуты игрока
  `TitleId` (рисуют все клиенты), `TitleCount`, `TitleLatest` (тосты).
* Отрисовка: `ReplicatedStorage/TitleBadge.luau` — общий рендерер для BillboardGui и окна.
* Убрана табличка титула над собаками в будках (`EconomyVisuals.client.luau`, функция
  `cosmetic()`); атрибут `EquippedCosmetic` у собак остался, но больше не рисуется.
* Тесты: `tests/titles.luau` (определения, условия, счётчики, троттлинг, миграция, надевание,
  снимок, атрибуты, стоимость, список окна, переводы). Изменён `tests/dogdex.luau`: проверка
  «титулы через DexRewards.TitleName» теперь смотрит `TitleDefinitions` вместо `EconomyVisuals`.
