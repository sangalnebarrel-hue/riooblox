# DOGROTS — план большой переработки

Документ основан на аудите `docs/OVERHAUL_AUDIT.md`. Варианты, которые аудиторы предлагали по каждой фиче, лежат в `docs/overhaul/F01…F12_*.md`. Здесь записаны **принятые решения**, общие контракты, порядок работ и критерии приёмки.

## 0. Неизменные правила

1. **Экономику сохраняем.**
   * Доход собак, `IncomeModel`, бусты, Robux-наборы и оффлайн-доход не меняются.
   * Меняются только явно заказанные числа: камень и кирки (F11), цена переброса в лаборатории (F12).
   * Новые награды (Dog Rush, титулы) считаются в «минутах дохода» с жёсткими капами.
2. **Игроков и данные сохраняем.**
   * `C.MegaResetVersion` не трогаем.
   * ID в конфигах (собаки, предметы, DNA, скины, слои, кирки) не удаляем и не переименовываем. Вывод из оборота — только флагом `Enabled=false` или `Retired=true`.
   * Новые данные лежат только под своим ключом `p.<Feature>={Version=1,…}`. Ключ создаёт `Normalize` фичи, а не `R.Profile`.
   * Читатели устойчивы к `nil`.
   * `Validate` никогда не отклоняет то, что лечит `Normalize`.
3. **Работающие механики не ломаем.** Старое выключаем флагом или переадресацией и оставляем адаптер. Удаляем только мёртвый код, причём файл заменяем заглушкой `-- retired`: если удалить файл из `src`, сборка вернёт оригинал из базы.
4. **Мир строится кодом.**
   * Сборка (`tools/build.py`) умеет создавать только скрипты и папки.
   * Новая геометрия описывается **чистыми модулями раскладки** (спецификации деталей) и создаётся общим строителем. Сервер строит коллизии и то, что должно быть общим для всех. Клиент строит декор, эффекты и LOD.
5. **Производительность — по бюджету** (§4). Новых `RenderStepped` и `Heartbeat` в фичах нет: только `Perf.Scheduler`. Нет `DescendantAdded` по всему Workspace: только теги CollectionService. Повторяемые объекты берутся из пулов.
6. **Каждая фича:**
   * модульная (свой Feature-модуль, свой Config, свой клиентский контроллер);
   * с тестом Lune;
   * с документом `docs/<FEATURE>.md` на русском;
   * с RU-переводами всех строк `T("…")` (это проверяют тесты).

## 1. Решения по вопросам владельца

Мы приняли решения сами, чтобы не останавливать работу. Каждое можно поменять конфигом.

| Тема | Решение | Почему |
|---|---|---|
| **F12. Какие процедуры остаются в лаборатории** | В меню консоли только **ПЕРЕБРОС МУТАЦИИ** за монеты. Шаги: выбрать собаку → цена → МУТИРОВАТЬ. Extraction («расщепление»), Targeting, Creation и рецепты выключены флагами `Enabled=false`, сервер отказывает. Данные (`p.Lab.*`) остаются. | Прямое требование: «убрать расщепления, лишние предметы, перегруженные меню» |
| F12. ASCEND (возвышение) | Механика сохраняется, но уходит из лаборатории в окно MY DOGS как контекстная кнопка. В лаборатории её нет. | «Не удалять рабочие системы», а меню лаборатории должно быть предельно простым |
| F12. Остаток ДНК у старых игроков | Одна идемпотентная конвертация (`Lab.Version=2`): остаток ДНК превращается в **бесплатные перебросы** `Lab.RerollCredits`. Курс не хуже, чем «сколько мутаций это ДНК могло оплатить». Копия хранится в `Lab.LegacyDNA`. Платная ценность не теряется. | Сохранность ценности без новых предметов |
| F12. Цена переброса | Растёт с редкостью собаки: `max(Floor[ранг], BasePrice×Share)`. Ориентир: 5K / 7K / 9K / 36K / 260K / 2,2M. Первая мутация бесплатна, как сейчас. Шансы те же: `Rules.VariantRows`, включая модификаторы событий. Если текущий вариант не Normal, нужно подтверждение. | Сейчас Secret перебрасывается за 14K при доходе в миллионы; сток сломан |
| F12. Где стоит колба | Вариант A. Колба стоит в центре здания `05_MutationLab` на месте `CentralChamber` и проходит сквозь крышу: радиус ~12, высота до Y≈95. Перед ней огромный пульт с промптом «АКТИВАЦИЯ». Крыша и балки вырезаются обратимо. | Ориентир на весь район, пульт внутри |
| F5. Глубины | 5 существующих слоёв = Поверхность / Глубина 1 / Глубина 2 / Глубина 3 / Редкая зона: Backyard / Caverns / Ancient Ruins / Cursed Depths / THE VOID. Под каждой из 5 ям участка вертикальная шахта в плите острова, шаг 8 стадов. Визуал следует `CurrentLayer`, старые игроки сразу видят свою глубину, никого не сбрасываем. | Предметы и цены по глубине уже есть в данных; ноль миграций |
| F11. Камень | Вся руда мини-шахты ×2. `LayerValue` {1,3,6,12,24} → {1,3,6,18,48}. Известняк по глубинам: 80–110 / 240–330 / 480–660 / 1 440–1 980 / 3 840–5 280. | Шахта ≈ 0,5–1× дохода собак без дерева, как задумано в `MINING.md` |
| F11. Кирки | Crystal 1,6M → **4M**, Inferno 12M → **60M**, Voidbreaker 85M → **600M**. Гири: Crystal Weight 1,5M, Inferno Core 20M, Void Mass 120M. Wooden, Stone, Iron, Steel не меняются. | «В несколько раз»: ×2,5 / ×5 / ×7. Окупаемость Voidbreaker ≈ 1 час общего дохода на L5 |
| F3. Витрина | Режим «Авто» (как сейчас) или «Вручную». Слотов 3, 4 или 5 в зависимости от стадии участка. Находка на витрине защищена от продажи, обмена и лаборатории, на карточке значок «НА ВИТРИНЕ». Центральная собака остаётся автоматической (от неё зависят секретные сцены). | Старые игроки видят ровно то же, пока сами не поменяют |
| F8. Покупка декора | В режиме «УКРАСИТЬ» прямо на своём участке. Скины-темы по-прежнему продаёт магазин COSMETICS. | Меньше беготни; декор — отдельный слой поверх темы |
| F6. Подарки и налог | Налога нет. Односторонний обмен разрешён, как сейчас, но с отдельным предупреждением. Пустые обмены не засчитываются в статистику. | Не меняем экономику; защищаем от случайностей и накрутки |
| F10. Показ титулов | Всем в радиусе 60 стадов, максимум 12 одновременно (на телефоне 8). Настройка «Все / Только мой / Выкл». | Без визуального мусора при 60 игроках |
| F7. Где бегут собаки | По дорожкам бульвара (линии DOG EXPRESS) и по петле у WelcomeHub. Позиции общие: сервер и клиент считают их по `GetServerTimeNow`, к игрокам ничего не привязано. | Не засоряет пространство; дёшево по сети |
| Иконки и звуки | Новых картинок и звуков сборка добавить не может. Иконки — эмодзи и существующие ассеты; звуки — встроенные звуки движка и уже прописанные ID. Всё через конфиги `GameIcons` и `UISound`, владелец может заменить ID. | Работает сразу; заменяемо |

## 2. Общие контракты (волна 0, их используют все фичи)

### 2.1 Сервер

* **Хуки `FeatureRegistry`.** Feature-модуль может объявить дополнительно к `Normalize/Validate/Action/Snapshot`:
  * `Actions={Name=true,…}` — свои действия. Пересечения имён проверяет тест.
  * `Cost(action)` — сколько токенов корзины стоит действие; по умолчанию 1.
  * `Gate(player,action,a,Runtime)` — проверки мира до транзакции: близость к витрине или пульту, свой участок. Отказ через `Rules.Check`.
  * `Request(player,action,a,receiptId,Runtime)` — полностью свой путь, как у `LabService`/`TradeService`. Если хук задан, `Runtime.Request` передаёт управление ему.
  * `Project(player,p,Runtime)` — публикация атрибутов участка и игрока после каждого `Runtime.Project`, обёрнута в pcall. Писать атрибуты только при изменении.
  * `Reply` = `'Snapshot'` | `'Patch'` | `'None'` плюс `Patch(player,action,result,p)` — лёгкий ответ без полного Snapshot.
* **Общие remote**: `ReplicatedStorage/Net/Remotes.luau`. `Remotes.Event(name)` и `Remotes.Function(name)`: сервер создаёт в папке `ReplicatedStorage.DOGROTS_Net`, клиент ждёт через `WaitForChild(name,30)`. Каждый обработчик проверяет типы и вызывает `Runtime.Allow`.
* **`Features/Settings`**: `p.Settings` со списком разрешённых ключей (качество, уменьшение движения, громкость UI/SFX/музыки, показ титулов, приём приглашений в обмен, подсказка «скрыть UI»). Действие `SettingsSave{Key,Value}`. Клиент получает настройки через Snapshot и атрибуты `Setting_<Key>`.
* **`ReplicatedStorage/ItemRarity.luau`** — единая редкость находки: Common…Secret, цвет и порядок. Считается по шансу, классу и мутации. Плюс экспорт `ItemValuation.Rarity`.
* **`Economy/ItemProtection.luau`** — реестр защит находок. `Register(name,fn(p,uid)->reason?)`, `Reason(p,uid)`. Его спрашивают `YardCommerce.CanSell` (продажа, «продать всё») и `ItemRules.Get(…,transfer)` (обмен, лаборатория). Избранное защищено от «продать всё», если не передан явный флаг `IncludeFavorites`.
* **Мелкие исправления горячих мест.**
  * `InventoryRevision` растёт только при реальном изменении инвентаря.
  * Пустой опрос Snapshot раз в 15 с убран или сильно реже.
  * `LabInfo`/`LabPreview` без `Refresh`.
  * Критическая гонка обмена `Confirm` исправлена (полный Trade 2.0 — в F6).
* **`tests/save_compat.luau`** — фикстуры профилей: новый; старый без новых полей; повреждённые поля; поле «будущей версии»; профиль-«кит» (220 собак, 1000 находок). Проверки: `Normalize`×2 идемпотентен, `Validate` проходит, круг через JSON, `Join → Leave → Flush` на памяти. Каждая следующая фича **дописывает свои фикстуры** в этот тест.

### 2.2 Клиент и мир

* **`ReplicatedStorage/Perf/`**:
  * `Quality` — уровень Auto/High/Medium/Low из настройки, `SavedQualityLevel`, «тач без клавиатуры» и сторожа FPS. Сам выставляет `LowFX` и `ReducedMotion`. Бюджеты `Budget(key)`.
  * `Scheduler` — один Heartbeat, `Every(hz,name,fn)`, нарезка ≤1 мс.
  * `Pool` — `Acquire`/`Release`, прогрев, статистика.
  * `Lod` — регистрация моделей по дистанции и пирамиде видимости, с гистерезисом.
  * `Maid`.
* **`WorldDetailQuality`** уважает атрибут `FXManaged=true` на источнике или предке, бюджеты берёт из `Quality`. Спор `PlotSkinMotion` ↔ WDQ устранён.
* **`ReplicatedStorage/World/Spec.luau` и `World/Builder.luau`**:
  * `Spec` — чистые функции спецификаций деталей: Block, Ball, Cylinder, Wedge, CornerWedge, Neon/Glass/Metal…, CFrame относительно якоря.
  * `Builder` — строит модель отдельно от мира, выставляет Parent одним действием, ставит атрибуты `BuilderId`/`LayoutVersion`/`PartCount` и режим стриминга.
  * Раскладки фич (колба, витрины, шахты, декор, модели предметов) возвращают спецификации, поэтому их можно тестировать в Lune и рендерить.
* **`tools/preview/`** — рендер спецификаций в браузере (three.js + Playwright → PNG). Нужен для художественного ревью колбы, предметов, витрин и шахт без Roblox Studio.
* **`ReplicatedStorage/UISound.luau`**:
  * SoundGroup `DOGROTS_AUDIO/{UI,SFX,Ambient}`, если их нет;
  * звуки hover, press, open, close, success, error, reward, whoosh;
  * пул до 6 одновременных звуков;
  * громкость из настроек.
* **Kit**:
  * общие токены: единая палитра редкости и вариантов, отступы, размеры иконок, тени;
  * `Kit.Motion` учитывает атрибут `ReducedMotion`;
  * кнопки и окна со звуками и анимацией наведения и открытия;
  * `GameIcons` получает набор глифов: редкость, действия, места.

## 3. Порядок работ (волны)

Машина позволяет 2 агента одновременно. В каждой волне две независимые ветки в своих worktree. Порядок волны такой:

* реализация → слияние → `tools/check.sh`;
* ревью: корректность и данные; производительность, утечки и визуал;
* исправления → пересборка → коммит и пуш.

| Волна | Ветка A | Ветка B |
|---|---|---|
| 0 | Серверный фундамент (§2.1) | Клиентский фундамент + `tools/preview` (§2.2) |
| 0′ | F11 баланс (числа, документы, симулятор) — делается сразу | |
| 1 | **F12 ядерная мутационная машина** | F10 титулы |
| 2 | F2 HUD, инвентарь, общий стиль + F9 «Скрыть UI» | F5 глубокая шахта |
| 3 | F3 витрина «Мои лучшие находки» | F4 модели предметов |
| 4 | F6 Trade 2.0 | F8 косметика участков |
| 5 | F7 Dog Rush | F1 «Показать путь» |
| 6 | Финальное ревью всего: данные, remote, утечки, бюджеты, новый и старый игрок, слабый ПК и телефон. Исправления. Документы. Финальная сборка. | |

**Горячие файлы.** Их правят многие: `Runtime.luau`, `GUIIntegration.luau`, `PawpadController`, `DOGROTS_AutoTranslateUI`, `Localization/Core`. После волны 0 новые фичи подключаются хуками и **не правят** `Runtime.Request`/`Runtime.Project`. Строки — в своём `Localization/<Feature>.luau`. Маршруты — одной строкой в `GUIIntegration`.

## 5. Критерии приёмки фич (кратко)

* **F1.**
  * В меню карты и в кнопках «ПОКАЗАТЬ ПУТЬ» строится реальный маршрут по улицам: граф из геометрии плейса.
  * По маршруту бегут светящиеся стрелки, которые поворачивают вместе с дорогой. У цели стоит финальный указатель.
  * Маршрут перестраивается, если игрок сошёл с пути, и снимается по прибытии.
  * Используется пул.
* **F2.**
  * Новый HUD с компактными кластерами и бейджами.
  * Новый инвентарь на Kit: вкладки, фильтры-чипы, сетка карточек с редкостью и ценой, панель деталей с **одним** главным действием, режим массовой продажи.
  * Звуки, наведение, анимации открытия.
  * Окно настроек.
  * Точки входа `GUIIntegration` сохранены.
* **F3.**
  * Подошёл к витрине на своём участке, нажал промпт у постамента — открылся выбор находок с превью.
  * Выбор сохраняется, гости видят витрину.
  * Эффекты редкости.
  * Находки на витрине защищены.
* **F4.**
  * У каждого из 108 предметов своя детальная процедурная модель: архетип плюс собственные детали.
  * Мутации видны, эффекты редкости.
  * LOD 0/1/2, кэш шаблонов.
  * Все пути превью идут через один фасад.
* **F5.**
  * Под ямами участка шахты с уровнями Поверхность → Глубина 1 → 2 → 3 → Редкая зона. У каждого уровня свой материал, свет и эффекты.
  * Собаки работают на полу текущего уровня.
  * Клиентские чанки и LOD.
  * Переход при открытии уровня.
  * Безопасность: ограждения, пол, спасение при падении.
* **F6.**
  * Приглашение без блокировки.
  * Две колонки «ОТДАЮ / ПОЛУЧАЮ», поиск, фильтры, редкость, количество, оценка стоимости.
  * Любое изменение сбрасывает готовность; отсчёт 5 с; подтверждение удержанием.
  * Атомарный журналируемый коммит.
  * Тесты на гонки.
* **F7.**
  * Отсчёт, волны собак по дорожкам, ловля с проверкой на сервере, комбо, золотые и радужные собаки.
  * Шкала события (Rush Pass) с наградами.
  * Итоговая карточка.
  * Звуки.
  * Никакой толпы, привязанной к игроку.
* **F8.**
  * Каталог декора: здания, растения, свет, декор, статуи, тематические зоны.
  * Режим «УКРАСИТЬ» с сеткой зон, призраком модели, поворотом и перемещением.
  * Проверка на сервере, капы по стадии.
  * Клиентский рендер с LOD.
* **F9.**
  * Кнопка-«глаз» и клавиша H плавно скрывают весь интерфейс, включая биллборды, промпты, CoreGui и чат.
  * Точное восстановление.
  * Автовозврат, если сервер открывает модальное окно.
* **F10.**
  * Каталог титулов с редкостью, цветом и градиентом.
  * Получение из существующих статистик и достижений, включая ретроактивно.
  * Окно титулов с прогрессом.
  * Титул над персонажем: пул, отсечение по дистанции.
* **F11.**
  * Числа из §1.
  * Документы и симулятор обновлены.
  * Тесты зелёные.
* **F12.**
  * Огромная колба и пульт.
  * Меню: собака → цена → МУТИРОВАТЬ.
  * Сервер: атомарный переброс с котировкой, без потери собаки.
  * Кинематика примерно 8 с с пропуском: подъём механизмом в трубу, энергия, жидкость, вспышки, смена цвета, финальная трансформация, крупная кнопка «ЕЩЁ РАЗ».
  * Короткая версия для телефона и режима Low.
  * Другие игроки рядом видят показ без смены камеры.

## 6. Проверка

* После каждой волны запускается `tools/check.sh`: сборка, verify, все тесты Lune, luau-lsp без новых диагностик.
* Для визуальных фич — рендеры `tools/preview` в `docs/img/overhaul/`.
* **Новый и старый игрок.** Тест `tests/save_compat.luau`, который расширяет каждая фича. В нём фикстуры профилей до переработки, профиль-«кит» и пустой профиль.
* **Слабый ПК и телефон.** Тесты бюджетов раскладок (число деталей, света, эмиттеров) и уровни `Perf.Quality`. Проверка «perf-lint»: в новых клиентских файлах нет своих `RenderStepped`/`Heartbeat` и нет `DescendantAdded` по workspace.
* **В Studio.** Итоговый чек-лист для владельца в `docs/OVERHAUL.md`: Play Solo, эмуляция телефона, MicroProfiler, Memory.
