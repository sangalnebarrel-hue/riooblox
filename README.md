# DOGROTS — изменения плейса

Исходник: `place/DOGROTS_MINING_6.rbxl` (как загружен). Результат: **`place/DOGROTS_MINING_7.rbxl`** — откройте
его в Roblox Studio. Все скрипты плейса выгружены в `src/` (дерево повторяет Explorer), поэтому каждое
изменение видно как обычный diff относительно первого коммита (`9b9bf06` — снимок исходного плейса).

Большая часть новой геометрии (кирки в руках, площадка копания, станция лифта, шахты, башня лаборатории,
пульт) строится серверными скриптами при запуске сервера — в Studio её видно после **Play / Run**.

## Что сделано

### Копание и кирки
- **Площадка копания** в зоне двора увеличена (31×20 стюдов вместо 23×18), с гравием, трещинами, рельсами,
  тележкой, фонарями; руда крупнее, у главной кучи четыре «спутника» поменьше.
- **Руда** реалистичнее и цветастее: фасеты, вкрапления, жилы, камешки у основания, особые детали
  (окаменелости, угольки, жеоды, призмы).
- **16 кирок** (деревянная + пак DOGROTS из 15): Сачок Ловец Бабочек, LEGO-Рука, Кирка 67, Мармеладный Ужас,
  Слизень-Гнилушка, Зубастый Будильник, Понирог-Дельфудель, Зомби-Франкенштейн, Клоун-Хрономорд,
  Мерзкий Спрут, Рука Судьбы, Смехопила, Алая Аниме-Коса, Когти-Близнецы, ТВ-Башка. Редкости
  Common → Mythic, цены от 750 до 10 млрд, у каждой: своя модель, idle-анимация, эффект удара, крит-эффект,
  звуковая «личность», стиль замаха (рубящий, тяжёлый, режущий, когти слева-справа), особенность и описание.
  Старые сохранения переносятся автоматически (прежние 7 кирок → ближайшие новые, понижения нет).
- **Кирка видна в руках**: в покое висит за спиной, во время копания — в руке (Когти — на обеих руках).
- **Анимации персонажа** без ассетов (Motor6D): выхватывание кирки, стойка, замахи, присед и рывок штанги;
  другие игроки видят то же самое.
- **Круги** разбросаны случайнее, появляются с анимацией, ореол цвета кирки.
- **Каждый удар** — вспышка, искры, кольца, частицы в стиле кирки; криты — отдельные большие эффекты.
- **Бесконечное комбо** 1x 2x 3x …: стили по нарастанию — радужный, лава, алмаз, космос, магия, робот,
  инопланетный; полоска «жара», вехи, сброс при промахе.
- **Сильная тряска экрана**, растущая с комбо.
- **Камера при копании вращается**: ПКМ/тач-перетаскивание/колесо/щипок, Q/E, R — сброс, стик геймпада.
- **Штанга** (качалка): празднование повторений — радужные кольца, пот, тряска, наезд камеры.

### Интерфейсы
- **Магазин кирок** — новое окно в стиле UI-кита: коллекция плиток, живая 3D-витрина кирки с эффектами,
  баннер редкости, описание и особенность, полоски характеристик, цена/сила, кнопки «Купить/Взять» и
  «Пробный удар», анимации открытия и выбора.
- **Пиксельный шрифт** (Press Start 2P) для заголовков, кнопок, подписей и табличек; длинные тексты —
  округлый FredokaOne, чтобы читались. Атрибуты `KeepFont` / `PixelFont` для исключений.
- **Свечение при наведении** на все кнопки (радужная обводка + лёгкий подъём) и на кликабельные объекты
  мира (подсветка). Атрибут `NoHover` — исключение.
- **Старые экраны** (~18 модулей: коллекционер, магазины, события, удача, офлайн-доход, хранилище и др.)
  перерисованы в стиле окон Dogs / Lab / Bag через общие примитивы `UITheme` (секции, вкладки, бейджи,
  полосы, модальные окна, анимация открытия).

### Лифт вместо мастерской
- Здание улучшений во дворах (Workshop) убрано; на его месте — **станция лифта** в шахты: копёр с колесом,
  противовесом и тросом, раздвижные двери, лампы глубины, табло. Логика улучшений сохранена: точка
  улучшений и зона взаимодействия перенесены в киоск станции; убранная мастерская хранится в
  `ServerStorage.MineRemovedWorkshops`.
- **Кинематографичный спуск**: затемнения-переходы, камера над кабиной с медленным облётом без стен в
  кадре, индикатор глубины, плавный возврат камеры.

### Пещеры
- Наполнение уровней шахты: камни, кристаллы, сталактиты, корни, крепь, рельсы, лампы, светящиеся зоны,
  туман, частицы, трещины, ниши; аккуратный акцентный свет. Бюджет деталей на уровень, проходы и места
  руды не загораживаются.

### Лаборатория
- **Огромная труба-реактор** над крышей — гиперболоидная градирня в духе башни Шухова (≈250 стюдов):
  скрученная стальная решётка, стеклянные барабаны со светящимися кольцами, бассейн охлаждения с
  пузырями, плазменный столб с двойной спиралью ДНК, корона с катушками Теслы, пар как у АЭС, шпиль с
  маяком.
- **Мега-пульт** вокруг оператора: командный стол с кнопкой ACTIVATE, крылья с матрицами кнопок,
  крутилками, рубильником и рычагами тяги, LED-панели и эквалайзеры, две приборные башни с экранами,
  шкалами, стрелочными приборами и лампами.
- **Простое меню** при взаимодействии — двухшаговое окно «выбери собаку → мутировать» (UI-кит).
- **Эффекты**: в покое по башне медленно ползёт радужная спираль, спираль ДНК переливается встречными
  радугами, бассейн и ядро плавно меняют оттенки, пар подкрашивается; пульт «живёт» — кнопки бегут
  радугой, лампы дышат случайными цветами, шкалы прыгают, LED-панели и эквалайзеры танцуют. Во время
  мутации пульт сходит с ума, рубильник захлопывается, рычаги уходят вперёд. Когда мутирует другой игрок —
  заряд поднимается по башне, радужная волна взбегает до короны и выпускает цветной пар.
  Учитываются «Уменьшение движения» и низкое качество графики; дальние игроки получают облегчённый режим.

## Как пересобрать плейс

Нужен [Lune](https://github.com/lune-org/lune) 0.11.

```sh
lune run tools/lune/check.luau                                   # компиляция всех скриптов src/
lune run tools/lune/build.luau place/DOGROTS_MINING_6.rbxl src place/DOGROTS_MINING_7.rbxl
```

`build.luau` берёт исходный плейс и подставляет исходники из `src/` (`*.server.lua` → Script,
`*.client.lua` → LocalScript, остальное → ModuleScript), недостающие папки создаёт.
`tools/render/` — простой программный рендер моделей для проверки геометрии без Studio.
